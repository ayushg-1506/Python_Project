# Smart Campus Information System 🎓

A complete Python web application for a Smart Campus Information System. This project integrates multiple academic modules into a single, cohesive dashboard with a modern, responsive UI.

## Features & Modules

This application consists of 8 integrated lab modules:

1. **Student Registration**: Register students and compute grades automatically from scores.
2. **Course Enrollment**: Manage student course enrollments (up to 5 courses) with credit tracking.
3. **Student Records**: Add and view student records, including event participation and set operations.
4. **Search & Sort**: Visualize Bubble Sort, Linear Search, and Binary Search algorithms on student IDs.
5. **Fee Calculator**: Compute total fees dynamically based on tuition, hostel, and transport costs.
6. **Academic Records**: File-based storage to track class marks, view average scores, and identify top performers.
7. **Directory Scanner**: Exception-handled directory tree scanner to explore server-side folders.
8. **Performance Analytics**: Data analytics and visualization (using Pandas and Chart.js) for subject-wise student performance.

## Tech Stack 🛠️

- **Backend**: Python, Flask, Pandas, NumPy, Matplotlib
- **Frontend**: HTML5, Vanilla CSS, JavaScript, Chart.js, Phosphor Icons
- **Deployment Ready**: Configured with `vercel.json` for serverless deployment on Vercel.

## How to Run Locally 💻

1. **Clone the repository** (if not already done) and navigate to the project root.
2. **Create and activate a virtual environment**:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. **Install the required dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Flask application**:
   ```bash
   python3 app.py
   ```
5. **Open your browser** and visit: `http://127.0.0.1:5000`
